# 1World Online

> Audience-engagement and interactive-advertising platform operating since 2012. 1World Online embeds
> Interactive Media Units — polls, quizzes, trivia, debates and surveys — into publisher pages in 30+
> languages, turns the resulting engagement into interactive ad inventory and first-party audience
> insight, and rewards participants with a points-based loyalty program and Web3 collectables
> (TravelVerse). It also runs a technology center for custom development and integration work.

## What an agent can and cannot do here

1World Online has a live first-party HTTP backend at https://app-wleu.1worldonline.com/ — declared by
1World Online's own frontend configuration and confirmed by the Spring Boot Actuator index the host
serves. It is NOT a public API: there is no developer portal, no API reference, and no
machine-readable contract of any kind. Every conventional specification path on the host
(/openapi.json, /openapi.yaml, /swagger.json, /v2/api-docs, /v3/api-docs, /api-docs, /swagger-ui.html,
/api/openapi.json, /v1/openapi.json, /swagger/v1/swagger.json and others) returns 404. No GraphQL
endpoint, AsyncAPI document, Postman collection, MCP server or A2A agent card was found on any host.

Access to the platform runs through publisher/advertiser partner registration, not through a
self-serve developer key. An agent cannot integrate with 1World Online from published material alone.

## Historical note

has been republished here as a contract, because it is not a surface 1World Online currently serves.
